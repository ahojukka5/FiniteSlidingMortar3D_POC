# Compressible neo-Hookean `TET4` bulk mechanics

This slice introduces the first finite-strain bulk element needed to turn the contact kernels into a complete boundary-value solver. It deliberately starts with a transparent total-Lagrangian `TET4` formulation whose analytical derivatives can be checked exhaustively before sparse assembly and nonlinear solution are added.

## Material model

The material is parameterized by positive shear and bulk moduli, \(\mu\) and \(K\). The first Lamé parameter is

```math
\lambda = K - \frac{2}{3}\mu.
```

For deformation gradient \(\mathbf F\) and \(J=\det\mathbf F>0\), the stored energy per reference volume is

```math
\psi(\mathbf F)
= \frac{\mu}{2}(\mathbf F:\mathbf F-3)
- \mu\ln J
+ \frac{\lambda}{2}(\ln J)^2.
```

Its first Piola stress is

```math
\mathbf P
= \mu\mathbf F
+ (\lambda\ln J-\mu)\mathbf F^{-T}.
```

The implemented material tangent is

```math
\mathbb A_{iJkL}
= \mu\,\delta_{ik}\delta_{JL}
+ \lambda F^{-T}_{iJ}F^{-T}_{kL}
+ (\mu-\lambda\ln J)F^{-T}_{iL}F^{-T}_{kJ}.
```

Singular or inverted states are rejected with `BulkGeometryError`; they are not regularized silently.

## `TET4` kinematics

The reference Jacobian is formed from the three edges starting at local node zero. Elements must have positive reference orientation. The constant reference shape gradients are obtained from the inverse reference Jacobian and satisfy

```math
\sum_{a=1}^{4}\nabla_X N_a = \mathbf 0.
```

For nodal current coordinates \(\mathbf x_a\),

```math
\mathbf F = \sum_a \mathbf x_a\otimes\nabla_X N_a.
```

The element energy, internal force, and tangent are

```math
\Pi_e = V_0\psi,
```

```math
\mathbf f_a^{\mathrm{int}}
= V_0\mathbf P\nabla_X N_a,
```

```math
K_{ai,bk}
= V_0\mathbb A_{iJkL}N_{a,J}N_{b,L}.
```

Because the formulation is total Lagrangian and the `TET4` gradients are constant, no additional numerical quadrature or separately assembled geometric-stiffness approximation is required. The complete derivative follows directly from \(\mathrm d\mathbf P/\mathrm d\mathbf F\).

## Verification

The deterministic patch mesh is a unit cube decomposed into 12 positively oriented tetrahedra by connecting a center node to two triangles on each cube face. An affine deformation must therefore be reproduced exactly in every element, and the center-node residual must vanish.

| Quantity | Result |
|---|---:|
| Reference volume | `1.0` |
| Minimum deformation Jacobian | `1.1282` |
| Interior-node residual norm | `1.985e-14` |
| Global force-balance norm | `2.391e-15` |
| Global moment-balance norm | `4.781e-15` |
| Maximum element deformation-gradient error | `1.866e-16` |

The directional tangent check shows second-order centered-difference convergence until floating-point roundoff dominates:

| Step | Relative error | Observed order |
|---:|---:|---:|
| `1.0e-2` | `1.239e-4` | — |

| `1.0e-3` | `1.239e-6` | `2.000` |

A randomized 199-state sweep over admissible large deformations produced maximum relative constitutive and element-tangent errors of `3.24e-10` and `3.22e-10`, respectively.

## Current boundary

The dense mesh assembler is intentionally verification-oriented. Sparse assembly, boundary conditions, external forces, Newton iteration, line search, augmented-Lagrange outer updates, and contact/bulk coupling remain separate later slices. Nearly incompressible locking and mixed or stabilized formulations must be evaluated before the `TET4` element is used as the final production discretization.
